feat(subscriptions): Implementar flujo de pago de suscripciones con Wompi

Se introduce un sistema completo para la renovación de suscripciones utilizando la pasarela de pago Wompi.

- **Flujo de Pago:** Los tenants con suscripciones vencidas son dirigidos a una página dedicada para seleccionar y pagar un nuevo plan.
- **Precios Dinámicos:** La página de planes muestra precios calculados y formateados según el país del tenant.
- **Integración Segura con Wompi:**
  - Se crea la Edge Function `create-subscription-checkout` para generar sesiones de pago seguras.
  - Se implementa la Edge Function `wompi-webhook-handler` para procesar notificaciones de pago y confirmar transacciones.
  - Se añade la función RPC `activate_subscription` para actualizar el estado de la suscripción del tenant tras un pago exitoso.
- **Auditoría:** Se añaden las tablas `payments` y `payment_intents` para una trazabilidad completa de las transacciones.

refactor(integrations): Modernizar lógica de integraciones y cifrado

Se refactoriza el sistema de gestión de integraciones y se mejora la seguridad del manejo de credenciales.

- **Gestión Dinámica:** El panel de Superadministrador ahora permite configurar cualquier proveedor de integración de forma dinámica.
- **Entornos de Prueba/Producción:** Se implementa la capacidad de gestionar credenciales para entornos de prueba y producción.
- **Seguridad Mejorada:** La lógica de cifrado se migra de funciones de base de datos a Edge Functions dedicadas (`encrypt-secret`, `decrypt-secret`).
- **Corrección de Bugs:** Se solucionan múltiples errores críticos relacionados con políticas de RLS, llamadas a RPC y el sistema de autenticación personalizado.

feat(plans): Mejorar gestión de planes de suscripción

Se mejora la experiencia de usuario en la gestión de planes desde el panel de Superadministrador.

- **Campo de Características:** Se añade un campo `features` (array de texto) a la tabla `subscription_plans`.
- **Editor de Etiquetas:** Se reemplaza el campo de texto simple por un editor de etiquetas (`react-tag-input`) en el formulario de edición de planes, mejorando la usabilidad.
