feat(notifications): Implementa sistema de notificaciones para clientes por Email y WhatsApp

Se implementa un sistema de notificaciones transaccionales completo y configurable para los clientes finales, con soporte para Email y WhatsApp.

**Características Principales:**

- **Canal de Email:**
  - Se crea una cola de envío (`client_email_queue`) y una Edge Function procesadora para manejar las notificaciones por correo electrónico.

- **Canal de WhatsApp:**
  - Se añade un sistema para almacenar de forma segura las credenciales de la API de Meta, soportando una arquitectura multi-plataforma con un "tenant propietario" por plataforma.
  - Se crea una cola de envío (`client_whatsapp_queue`) y una Edge Function (`process-whatsapp-queue`) que se ejecuta cada minuto para enviar los mensajes.
  - Se implementa un Webhook (`whatsapp-webhook`) para recibir mensajes, con validación de seguridad y lógica para procesar respuestas a botones y consultas de texto.

- **Integración y Flujos:**
  - Se integran las notificaciones (Email y WhatsApp) en los flujos de negocio clave: creación de citas, cancelación, pago (recibo) y facturación.
  - Se reutiliza y refactoriza la lógica de encolamiento en funciones de base de datos (`plpgsql`).

- **Configuración de Tenant:**
  - Se añade una nueva pestaña "Notificaciones" en el panel de configuración del tenant.
  - Los administradores del tenant pueden activar o desactivar individualmente cada tipo de notificación para cada canal (Email/WhatsApp).
  - La interfaz es responsiva y se adapta a dispositivos móviles.
