refactor(superadmin): Corrige navegación y optimiza carga de datos

Se realizan múltiples mejoras en el panel de superadministrador para solucionar errores de navegación, optimizar el rendimiento y estandarizar el acceso a datos.

- **Corrección de Navegación:**
  - Se auditaron todos los enlaces del menú (`navigation.ts`) contra las rutas definidas (`routes.tsx`).
  - Se corrigieron las URLs incorrectas y se añadieron las rutas faltantes para `Integrations`, `SystemAlerts`, `ErrorReports`, `PerformanceMetrics` y `Translations`.
  - Se creó una página placeholder para "Gestión de Accesos" para completar el enrutamiento.

- **Optimización de Rendimiento:**
  - Se solucionó la carga lenta de la lista de plataformas, causada por una consulta ineficiente.
  - Se implementó el patrón estándar de acceso a datos:
    1. Se creó una función RPC (`get_platforms_list`) con búsqueda del lado del servidor.
    2. Se actualizó la Edge Function para usar esta RPC.
    3. Se refactorizó el componente de React (`PlatformsList.tsx`) para usar `react-query` con búsqueda y debounce.

- **Documentación:**
  - Se documentó formalmente el "Estándar de Acceso a Datos para Listas" en `Glamtica.md`, estableciendo el uso de RPCs como la práctica recomendada.
