feat(superadmin): Implementa el motor de gestión de integraciones

Se introduce un sistema completo para que el superadministrador pueda definir y gestionar proveedores de integración (ej. facturación, pagos) por país.

- **CRUD de Categorías:**
  - Se añade una tabla y un gestor en la UI para crear, editar y eliminar tipos de integración (ej: "Facturación Electrónica").
  - La gestión se encuentra en `Configuración Global > Integraciones`.

- **Gestor de Proveedores:**
  - Se crea un dashboard en `/superadmin/integrations` para listar los proveedores definidos.
  - Se implementa un formulario completo para crear/editar proveedores, permitiendo definir:
    - Información básica (nombre, país, categoría).
    - Un `slug` programático para uso interno.
    - Endpoints de API para entornos de prueba y producción.
    - Un constructor de campos para las credenciales que debe proporcionar el tenant.
    - Un compositor visual (placeholder) para mapear el JSON de la API a las variables de Glamtica.

- **Backend:**
  - Se añaden todas las migraciones de base de datos necesarias para las tablas `integration_categories` y `integration_providers`.
  - Se ajustan los permisos de las nuevas tablas para alinearse con la arquitectura de seguridad existente (GRANT).
